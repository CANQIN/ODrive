# Repository conventions

## Git commit messages

- Use the format `<English prefix>: <中文说明>` for commit messages.
- Choose an English prefix appropriate to the change, such as `feat`, `fix`,
  `refactor`, `docs`, `build`, `test`, or `chore`.
- Write the summary after the colon in Chinese.
- Example: `refactor: 显式传入无感估算器输入并解除轴依赖`
